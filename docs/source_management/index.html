or an API request
Client certificate (if the API requires one)

The certificate goes only to your eyetable API and is stored encrypted with the source, so Reload and schedules use it without the file.

Paste a curl command from your browser's dev tools (Copy as cURL), API docs or Postman. To load every page, include where to start and the page size, e.g. page=1&per_page=100 or offset=0&limit=100; an API that returns a next-page link (like nextLink) is followed on its own. Tokens, keys and passwords in the command are stored encrypted.

or a database

An ODBC or JDBC connection string (SQL Server, Azure SQL, Dataverse; Authentication=ActiveDirectoryInteractive signs in with Microsoft Entra and MFA), or a URL such as postgresql://user:password@host:5432/db. eyetable lists the tables and views; pick the ones to bring in, each as its own source. The password goes only to your eyetable API and is stored encrypted.

Reloads run here in the background, so the page stays usable while big tables load. Each shows its rows so far against the table’s row count before the load.
